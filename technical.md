# x4studio: technical notes

How the studio is made, what it writes in a project, and how to build it. What it is for is in [README.md](README.md).

## Principles

- **Pages of real components.** The surface builds the x4 components themselves, made inert, with a layer above them for the selection. The try mode takes the layer away.
- **One description, two outputs.** A page is a tree of nodes, kept as data. `describe( node )` ([src/core/components.ts](src/core/components.ts)) says what a node is in x4; the surface and the code generator both start from it, so what is seen is what is generated.
- **Components are data.** The studio knows no component by name. They are described in [src/components.json](src/components.json): the x4 class, the properties, what a container accepts, the items of a list. A project adds its own in `.x4studio/components.json`. The CSS properties of the inspector and the colors of a theme are described the same way.
- **Generated code is derived from, never edited.** The document of a page is kept in a comment at the end of its generated file, which is how the studio opens it again.

## What it generates

A page named "Demo" becomes `src/pages/demo.ui.ts`:

```ts
/**
 * GENERATED BY x4studio - DO NOT EDIT
 * Derive from this class: what is written here is lost when the page is saved.
 */

import { BoxProps, BtnGroup, Button, Input, Label, VBox } from "x4js";
import icons from "../icons";
import "../styles.ui.css";

export class DemoUI extends VBox {
	declare protected refs: { form: VBox, user: Input, buttons: BtnGroup, help: Button };

	constructor( props: BoxProps ) {
		super( props );

		this.setContent( [
			this.refs.form = new VBox( { cls: "card", content: [
				new Label( { cls: "title", text: "Sign in" } ),
				new Label( { text: "User name", icon: icons.user } ),
				this.refs.user = new Input( { type: "text", placeholder: "name" } ),
				this.refs.buttons = new BtnGroup( { align: "right", items: [
					this.refs.help = new Button( { label: "Help", icon: icons.help } ),
					"-",
					"ok.default",
					"cancel.outline",
				] } ),
			] } ),
		] );
	}
}

/* x4studio:document
{ "format": "x4studio/page", "version": 1, "class": "DemoUI", "root": { ... } }
*/
```

The components that were given a name are members of `refs`, typed. A class of the project is a `cls`; what a component sets for itself is its `style`.

## A project

A project is a folder. On the web it is a zip held in memory, opened and exported as a whole, and kept in the browser (IndexedDB) between two sessions. Everything that touches a file goes through one small interface (`ProjectStore`, [src/core/store.ts](src/core/store.ts)), which a folder on the disk can stand behind later.

    .x4studio/           what only the studio reads: project.json, styles.json, theme.json, chat.json
    src/pages/*.ui.ts    the generated pages
    src/styles.ui.css    the classes of the project
    src/theme.ui.css     the theme, imported once by the application
    src/icons/*.svg      the icons
    src/icons.ts         the module that exports them

## The assistant

The chat calls the API of Anthropic from the page, with `fetch`. The model is told what the descriptions say (the components, the CSS properties), is sent the state of the studio with each message, and acts on the page through tools (`get_page`, `add`, `set`, `move`, `remove`, `set_class`, `open_page`, `add_page`). What a tool is given is checked against the descriptions. The key is kept in the `localStorage` of the browser, never in the project.

## Building

The studio builds against the sources of x4, not yet against the npm package: it uses what x4js 2.3.17 brings, which is not published. Until then it expects the x4 repository beside this folder, as `../x4-2025` (the `paths` of [tsconfig.json](tsconfig.json)), and uses its TypeScript and its command line:

    npm install                                                               # the font, and playwright
    node ../x4-2025/node_modules/typescript/bin/tsc -p .                      # types
    node ../x4-2025/demo/notes/node_modules/x4js/bin/x4js.mjs build --debug   # build, into bin/

Serve `bin/` and open `index.html`: the studio starts on a demo project.

## Sources

- [src/core/](src/core/): no DOM, runs under node. The descriptions of the components, the tree of a page, the code generator, the styles, the theme, the icons, the project and its zip, the assistant.
- [src/view/](src/view/): the x4 components of the studio. The surface, the inspector, the project and theme panels, the chat, the tree, the palette.
- [src/main.ts](src/main.ts): the host.
- [src/components.json](src/components.json): the components, the CSS properties and the colors of a theme, as data.
- [src/demo.json](src/demo.json): the demo project.
- [todo.md](todo.md): what was decided and why, what is done, what is open.
